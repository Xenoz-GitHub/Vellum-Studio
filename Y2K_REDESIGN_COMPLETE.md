## 🚀 How to Run

1. **Install dependencies** (if not already done):
   ```bash
   npm install
   ```

2. **Start the dev server**:
   ```bash
   npm run dev
   ```

3. **Open in browser**:
   - Navigate to `http://localhost:3000`
   - The landing page will load with the new Y2K design

4. **Try the demo account**:
   - Click "TRY DEMO" button on landing page
   - You'll be taken to the dashboard with demo presentations
